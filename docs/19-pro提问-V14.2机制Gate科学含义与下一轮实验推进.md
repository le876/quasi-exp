### 4.5 当前 fresh audit Gate 的实际定义

`v14_2_selected_section_audit.py` 的 metric 定义为：

```python
finite = all non-null finite values
gate_pass = (
    len(finite) > 0
    and missing == 0
    and len(finite) == len(values)
    and p95 <= registered_p95_limit
    and max <= registered_max_limit
)
```

因此该布尔量同时受以下因素影响：

- selected section 的几何 gap；
- fresh continuation 是否成功；
- bounds 和 residual `<=3 mm`；
- 是否存在可审计 path/cycle/repeat 样本。

本文只陈述该实现耦合；是否属于错误耦合是本次请 GPT-5 Pro 判断的问题。

### 4.6 当前 largest component 的实际定义

runner 对 primary-covered nodes 建立 adjacency。只有当一条 selected edge 的两端都被 primary partition 分配给该 edge 所属 chart 时，该 edge 才进入该 chart 的 primary adjacency。largest component ratio 是最大 connected component node count 除以 patch task-node count。

该定义不把两个不同 root chart 仅因 beta 接近而合并，也没有在统计前构造 stitchable chart overlap graph。

# 核心判断

当前的 V14.2 **不是“section-first 失败”**，而是取得了一个明确的机制性进展之后，被两个不恰当的 Gate 和一个尚未完成的搜索实现卡住了：

1. **section-first 已经基本解决了 V14.1 的 candidate flood。**
   相比 F1 的约 (9.3\text{万}\sim10.3\text{万}) 次 continuation、覆盖率 (0.844\sim0.928) 且仍然触发 cap，S4 只用了约 (7.6\text{k}\sim9.5\text{k}) 次 continuation，就在四个 patch 上获得了 (100%) 的节点覆盖且没有 cap hit，计算量降低了约一个数量级。

2. **当前 method Gate 的失败主要不能解释为几何 section 不成立。**
   在 (58{,}915) 条 fresh audit 记录中，只有 (3) 条是明确的几何 gap，另外 (242) 条都是数值求解失败；但当前 `_metric()` 把两者都压成同一个 `gate_pass=false`。约 (98.8%) 的失败记录并不是已证明的 branch 不一致。

3. **当前 largest component 指标没有测量真正可部署的 coherent atlas。**
   它测量的是“逐点选择 primary chart 后，只保留同一 chart 内 growth edges”形成的连通分量，而没有合并在重叠区中彼此一致的 root charts。当前 (0.375\sim0.5625) 的数值可能是 chart ownership 被局部打碎后的结果，不能直接解释为工作空间中不存在大于 (60%) 的一致区域。

4. **但 S4 目前也还不能直接冻结。**
   我检查了归档中的实际执行代码后发现，当前所谓 beam 并不是严格意义上的 beam search：每个节点虽然保存最多 (K) 个 hypotheses，但下一波传播只使用 `selected[parent_id]`，即每个父节点的第一名 hypothesis；其余 hypotheses 从未继续传播。因此 S4 与 S8 完全相同，只能说明“当前局部保留上限没有影响第一名”，不能证明全局 section 搜索已经饱和。

因此，当前主要矛盾已经进一步演化为：

$$
\boxed{\text{多个局部 root-consistent charts 的广域覆盖}
\quad\text{与}\quad
\text{一张经过全局路由、可拼接、可验证的单值监督场}}
$$

当前起决定作用的主要方面是 **chart qualification、chart stitching 和全局 primary atlas 构造**。数值 solver 鲁棒性、Reach 边界继续收敛和 Student 容量仍是次要矛盾。

下一步不应继续扩大 flood cap，也不应直接运行当前版本的 5k。应先做一轮短而有针对性的 **BACRA V14.2R：Gate Decomposition and Stitched-Atlas Repair**，随后立即进入 12-patch、repaired 5k 和 20k–50k Student。

# 三、当前代码实现中的关键瓶颈

我直接检查了归档中实际运行的 `v14_2_section_first_atlas.py`、`v14_2_selected_section_audit.py` 和 `v14_2_runner.py`。这些文件是本轮的 executed source。

## 3.1 `missing_count==0` 把两种不同命题错误地耦合了

当前 `_metric()` 的逻辑本质上是：

```python
finite = all finite gap values

gate_pass = (
    finite is nonempty
    and missing == 0
    and every scheduled value is finite
    and p95 <= threshold
    and max <= threshold
)
```

因此它同时检验：

### 命题 A：几何一致性

当 continuation 成功时：

$$
d_\beta\bigl(\operatorname{Cont}_{i\to j}(\beta_i),\beta_j\bigr)
\le\epsilon
$$

### 命题 B：当前数值实现一次就能完成所有 schedule

$$
\operatorname{SolverSuccess}(s)=1,\qquad\forall s
$$

这两个命题不等价。

只要一次 corrector 因迭代预算、分段步长、fallback 或边界检查失败，即使正确的 section 仍然存在，也会让 geometry Gate 失败。随着 audit schedule 数量扩大，“一次运行零失败”的条件还会越来越苛刻，因而它不能作为 mechanism existence Gate。

### 正确处理方式

应拆成三套指标：

$$
G_{\mathrm{geometry}}
$$

只对成功求解或经过注册 retry 恢复的 schedule 计算 endpoint、cycle 和 multipath gap。

$$
G_{\mathrm{solver}}
$$

记录 first-pass、retry-recovered、persistent failure。

$$
G_{\mathrm{certificate}}
$$

要求最终保留的 primary atlas 的必要验证边全部可验证；持续失败的边必须被移除或转为 abstention。

探索阶段可以允许 first-pass numerical failure，但不能允许 retained certificate 中仍有 unresolved edge。

---

## 3.2 当前 audit 并不只审计最终 primary atlas

`audit_selected_sections()` 会遍历 `growth.charts` 中的全部 root charts，最终 `gate_pass` 要求：

```python
all(chart_gate.values())
```

这意味着：

- 某张 chart 即使完全没有承担 primary labels；
- 某张 chart 即使仅覆盖很小区域；
- 某张 chart 即使应当被另一张 chart 支配并删除；

它的一条 numerical failure 仍然可以否决整个 patch。

这不符合 atlas 的科学含义。正确逻辑应该是：

1. 先逐 chart 进行 qualification；
2. 删除太小、冗余或不稳定的 chart；
3. 对剩余 charts 做 stitching；
4. 生成 primary atlas；
5. 最后只对实际保留的 primary field 和 transition edges 做硬 Gate。

注册参数 `minimum_alternative_chart_cells=8` 在四 patch 的 section growth 和 mechanism Gate 中并没有真正参与 chart pruning，它只在后面的 5k root retention 中使用。这也是当前许多小 chart 可能干扰 Gate 的原因之一。

---

## 3.3 当前 largest component 不是 deployable coherent region

当前 `_component_ratio()` 只在以下条件下保留一条边：

```python
primary_chart[left] == chart_id
and primary_chart[right] == chart_id
```

因此，即使两张 chart 在重叠区给出几乎相同的 (\beta)，只要左右节点被分配给不同 chart，这条边就被删除。

当前指标测量的是：

$$
\rho_{\mathrm{current}}
=======================

\frac{
\text{逐点 primary 分配后，同 chart growth-edge 最大分量}
}{
\text{全部 task nodes}
}
$$

而真正需要测量的是：

$$
\rho_{\mathrm{deploy}}
======================

\frac{
\text{经过 chart stitching、全局路由和 boundary abstention 后的最大验证分量}
}{
\text{全部 task nodes}
}
$$

二者不是同一个对象。

更关键的是，5k runner 的后半段实际上已经实现了初步的 `chart_transition_audit`：它会在跨-chart task edge 上比较两张 chart 在两个端点的 (\beta) gap，并对 non-stitchable boundary 做 abstention。但这套更合理的逻辑位于 repaired 5k 阶段，而 repaired 5k 又被前面的错误 component Gate 阻止。

这构成了一个程序结构上的循环阻塞：

$$
\text{需要 stitching 才能正确判断 component}
$$

但

$$
\text{必须先通过未 stitching 的 component Gate 才能运行 stitching}
$$

应将这套 chart-transition 逻辑前移到四 patch 和 12-patch 阶段。

---

## 3.4 当前 S4 并不是真正的 beam-4

当前 `_grow_chart()` 的实际流程是：

```python
hypotheses[target_id] = tuple(retained)
selected[target_id] = retained[0]
```

下一轮传播时使用的是：

```python
parents = [selected[parent_id] ...]
```

所以每个节点虽然存了多个 hypotheses，但只有第一名继续传播。其他 hypothesis 不会产生后代，也不会在后续闭环中重新竞争。

因此当前方法更准确的名称应当是：

> 多 root、每节点 greedy top-1 的 section growth，并保留局部备选 endpoint。

而不是全局意义的 beam search。

S4 与 S8 完全一致能证明：

- 每节点局部 cluster 数没有超过 (4)，或者超过时第一名没变；
- 当前 greedy top-1 对保留上限不敏感。

它不能证明：

- 第二名局部 endpoint 不会在远处形成更好的 section；
- alternative lineage 不会修复后续 cycle；
- root 集合已经饱和；
- 全局 canonical field 已经唯一。

### 下一步不必立刻大改成复杂 beam

先统计：

- 每个 `(chart,node)` 的 hypothesis count；
- hypothesis count (>1) 的节点比例；
- 当前 alternative hypotheses 是否从未被传播；
- K1、K2、K4 的结果是否已经完全一致。

如果绝大多数节点只有一个 cluster，那么 beam 宽度本来就不是当前主要参数，可以把方法明确冻结为 greedy rooted section，而不必过度工程化。

只有在 alternative hypotheses 确实大量存在，并且 root 或 downstream cycle 对它们敏感时，才实现真正的 beam propagation。

---

## 3.5 当前 score 不是累计 section 代价，而且跨 chart 不可直接比较

当前 proposal score 包括：

- 同一目标点不同父节点 endpoint 的 agreement；
- 与各自 root beta 的姿态距离；
- margin；
- residual。

但它没有加入 `source.score`，即不是：

$$
S_i=S_{\operatorname{parent}(i)}+\Delta S_{i}
$$

而只是当前节点的局部代价。

此外，不同 chart 使用不同 root，因此：

$$
d(\beta_i,\beta_{\mathrm{root},k})
$$

在不同 chart 间没有统一标尺。逐点比较这些 root-relative scores，可能产生 salt-and-pepper 式的 chart ownership。

primary atlas 应通过一项全局图优化构造，而不是逐点最小化 root-relative score。

---

## 3.6 `patch_07` 是局部真实问题，但不是全局否定

当前仅有三个明确的几何失败：

- 两个 `selected_endpoint_gap`；
- 一个 `cycle_return_gap`。

它们全部在 `patch_07`，edge max 为 (1.0166^\circ)，cycle max 为 (1.0615^\circ)，只是略高于 (1^\circ) 阈值。其余有限样本的 P95 仍低于 (0.5^\circ)。

这更像以下三种情况之一：

1. 同一条问题 edge 的正反向记录，加上包含它的一个 cycle；
2. 一个局部高条件数或边界区域；
3. 一处真正的 branch/holonomy 缺口。

必须先按 unique edge/node/cycle 去重和局部复算，不能把三条 row 当作三个独立空间反例。

## Phase 2：failed-schedule 定向复算

### 实验目的

将 (242) 条 numerical failure 分成“预算可恢复”“持续数值失败”“局部几何不一致”三类。

### 实验原理

一个几何命题不应由单一数值预算决定。所有 retry 必须预注册，且真正的 continuation recovery 不能使用目标节点 canonical beta 作为 oracle seed。

### 实验步骤

对去重后的每个失败 entity 运行三级 source-only retry：

| 层级 | 分段步长 | corrector 预算 | solver |
| -- | ------: | -----------: | --------------------------------- |
| R0 | 5 mm | 当前值 | 当前流程 |
| R1 | 2.5 mm | (2\times) | weighted DLS + bounded LS |
| R2 | 1.25 mm | (4\times) | weighted DLS + bounded LS + SLSQP |

每个层级执行：

1. forward；
2. reverse；
3. 三次完全重复；
4. 记录 residual、bounds、iterations、endpoint gap；
5. 单独运行一个 oracle-target-seed 诊断，但不得计入 continuation pass。

输出：

```text
failed_schedule_retry.parquet
retry_recovery_summary.json
persistent_failure_entities.parquet
```

### 分类规则

**A. Recoverable numerical failure**

source-only retry 成功且：

$$
d_\beta\le1^\circ,\qquad r_{\mathrm{FK}}\le3\ \mathrm{mm}
$$

**B. Persistent numerical failure**

所有 source-only retry 均失败，但 target canonical beta 本身 FK 可行。

**C. Geometric/branch disagreement**

source-only continuation稳定成功，但收敛 endpoint 与 selected target label：

$$
d_\beta>1^\circ
$$

**D. Local feasibility failure**

target canonical beta、continuation 和 direct corrector 均无法满足 residual/bounds。

### 新 Gate

不再要求所有 raw schedule 一次成功。

硬条件改为：

- 最终 retained primary certificate 中没有 persistent numerical failure；
- persistent failure 所在 edge/node 必须被移除或 abstain；
- recovery 后的 geometry 仍满足原阈值。

---

## Phase 3：`patch_07` 局部反例审计

### 实验目的

判断 `patch_07` 是单个局部边界问题，还是静态 section 的系统性反例。

### 实验原理

真正的 branch 问题应具备空间持久性，而不是只出现于一个数值 schedule。

### 实验步骤

1. 找到三个失败 row 对应的 unique edge、nodes 和 cycle；
2. 构造其 1-ring 和 2-ring task neighborhood；
3. 对 neighborhood 的所有 task edges 执行 R0–R2；
4. 分别从 edge 两端、cycle 两个方向进行 continuation；
5. 对附近目标点使用不同 root lineage 到达；
6. 记录同一 target 的历史内重复 gap 与历史间 gap。

### 通过条件

以下任一情况均允许保留方法：

- 三条 row 实际源于同一问题 edge，复算恢复；
- 问题局限于一小片 boundary，abstain 后 stitched component 仍达到 (0.60)；
- chart split 后两侧各自 audit 通过。

只有出现以下情况才判定当前 static section 方法失败：

- (>1^\circ) 差异在 2-ring 内成片扩展；
- 多种 solver 和步长下稳定复现；
- chart split 或小规模 abstention 不能隔离；
- 删除该区域后 coherent component 跌破要求。

## Phase 4：chart qualification 与 stitchability audit

### 实验目的

把多个 root charts 组装成真正可部署的 atlas。

### 实验原理

设 chart (k) 在域 (\Omega_k) 上给出：

$$
c_k:\Omega_k\rightarrow\mathbb R^6
$$

两张 chart 只有在重叠区域一致时才能 stitch：

$$
Q_{0.95}\left(
d_\beta(c_k(x),c_l(x))
\right)\le0.5^\circ
$$

且：

$$
\max d_\beta(c_k(x),c_l(x))\le1^\circ
$$

### 实验步骤

#### 4.1 Chart qualification

逐 chart 检查：

- 覆盖至少 8 个独立 cells；
- FK residual/bounds 合格；
- retained certificate audit 合格；
- root-path、cycle basis 和 repeat 合格；
- 若一张 chart 被另一张 chart 完全覆盖且 overlap gap 很小，则删除 dominated chart。

#### 4.2 构造 chart overlap graph

图节点为 qualified charts。

如果两张 chart：

- 有足够 overlap；
- overlap gap 通过；
- 跨 chart transition edge 的 forward/reverse continuation 通过；

则建立 stitch edge。

#### 4.3 计算 stitchable chart union

chart overlap graph 的每个连通分量对应一个可拼接 atlas component。

此时才计算：

$$
\rho_{\mathrm{stitched}}
========================

\frac{\text{最大 stitchable union 覆盖节点数}}
{\text{patch 总节点数}}
$$

#### 4.4 全局 primary chart assignment

不要逐点直接取最低 root-relative score。应求解：

$$
\min_{{z_i}}
\sum_i U_i(z_i)
+
\lambda\sum_{(i,j)\in E_X}V_{ij}(z_i,z_j)
$$

其中：

- (z_i) 是节点 (i) 选择的 chart；
- (U_i) 使用 residual、margin、condition 等可跨 chart 比较的指标；
- (V_{ij}) 惩罚 chart switch 和 beta discontinuity；
- non-stitchable transition 的代价设为无穷；
- 无法稳定分配的节点进入 abstention。

可以先复用项目中已有的 ICM 框架，多初值运行并检查解稳定性。

#### 4.5 审计完整 primary task graph

当前 audit 只审计 growth 中实际被选作 parent 的 edges。新版本还应检查最终 primary atlas 中的 task-neighbor edges：

- same-chart neighbor；
- cross-chart stitch transition；
- spanning tree；
- cycle basis；
- maximin long paths。

### 四 patch Gate

每个通过的 patch 必须满足：

| 指标 | 阈值 |
| ------------------------------------- | ----------------------------: |
| primary label coverage | 不低于 (0.90) |
| largest stitched coherent component | 不低于 (0.60) |
| geometry P95 | 不高于 (0.5^\circ) |
| geometry max | 不高于 (1^\circ) |
| repeat P95 | 不高于 (0.2^\circ) |
| retained FK residual max | 不高于 (3) mm |
| unresolved critical certificate edges | (0) |
| nonstitchable boundary | 可 abstain，但不得破坏 coherent Gate |

四个 diagnostic patches 至少 (3/4) 通过，才能进入 12-patch。

## Phase 5：搜索稳定性重新定义

### 实验目的

验证最终 stitched primary atlas 对搜索策略稳定，而不是只验证局部 K 上限。

### 实验原理

真正需要稳定的是：

$$
x_i\mapsto\beta_i^*
$$

而不是内部保存了多少 candidates。

### 实验步骤

先运行低成本对照：

| 对照 | 含义 |
| ------------------ | --------------------------- |
| K1/K2/K4 | 判断局部 alternatives 是否真正存在 |
| R3/R5/R8 | 改变 root candidate 数 |
| leave-one-root-out | 判断某个 root 是否决定整个 atlas |
| 三组 root 排序/seed | 判断 root registry 敏感性 |
| greedy vs S4C | 判断局部 consensus repair 是否有作用 |

比较的是经过 stitching 和全局 primary assignment 后的结果，而不是 chart ID 本身。

### 稳定性 Gate

$$
J_{\mathrm{coverage}}\ge0.95
$$

$$
Q_{0.95}(d_\beta)\le1^\circ
$$

$$
\max d_\beta\le2^\circ
$$

$$
\text{primary assignment change}\le5%
$$

$$
\text{verified edge change}\le5%
$$

### 是否实现真正 beam 的条件

只有出现以下任一情况时才实现真正 beam：

- 大量 `(chart,node)` 有多个可用 hypotheses；
- leave-one-root-out 导致 primary labels 大幅改变；
- alternative hypothesis 能修复 `patch_07` cycle；
- greedy 的 cycle/multipath Gate 反复失败。

真正 beam 中应让所有保留 hypotheses 继续传播，并使用累计分数：

$$
S(h_i)
======

S(h_p)
+
w_\beta d_\beta(\beta_i,\beta_p)
+
w_r r_i
+
w_m\phi(m_i)
+
w_c C_i
$$

而不是只存储但不传播。

## Phase 6：12-patch confirmation

### 实验目的

检验修复后的方法能否从四个 diagnostic patches 泛化到完整的 (8+4) patch 集。

### 实验原理

允许少量难区域被 abstain，不要求所有 patch 都通过；但 development 和 confirmation 必须分别有足够成功率，防止只针对四个已知 patch 调参。

### 实验步骤

1. 完全冻结代码、配置、阈值和 retry schedule；
2. 对 12 patches 运行同一方法；
3. 每个 patch 输出：

   - qualified charts；
   - stitch graph；
   - primary atlas；
   - abstention region；
   - primary certificate；
   - root/search stability；
4. 不允许根据 confirmation patches 再改阈值。

### 通过条件

沿用原本合理的统计要求：

- development 至少 (6/8)；
- confirmation 至少 (3/4)；
- 通过 patch 的 largest stitched component 中位数 (\ge0.60)；
- single-cell/tiny charts 不占主导；
- retained primary certificate 全部通过；
- search stability 通过。

达到后冻结的应是：

> rooted section-first + chart qualification + stitchable atlas + global primary assignment

而不是单独的 S4 数字。

# 七、BACRA V14.3：Repaired 5k Pilot

## 实验目的

第一次在 Omega200 的广域工作空间上测量：

- 有多少空间可以获得 canonical labels；
- 最大静态 coherent region 多大；
- 是否足以生成 20k 以上唯一监督数据；
- xyz-only Student 是否可学。

## 实验原理

多个 root charts 独立生长，通过 overlap consistency 和 transition audit 拼成 atlas。无法拼接的边界允许 abstention，而不是强迫不同 branch 混入同一监督表。

## 实验步骤

1. 使用 frozen empirical lower Reach proxy；
2. 对 5000 parent cells、约 25,000 task probes 建图；
3. 选取 32 个 task-space maximin roots；
4. 每个 root 生成 rooted chart；
5. 使用 V14.2R 的 chart qualification；
6. 构造 global stitch graph；
7. 删除 dominated charts；
8. 全局优化 primary chart assignment；
9. 对 nonstitchable boundaries 生成 abstention band；
10. 对 primary certificate 做 fresh retry audit；
11. 输出唯一监督表和 alternative chart 表。

### 主要输出

```text
qualified_charts.parquet
chart_overlap_audit.parquet
chart_stitch_graph.parquet
global_primary_assignment.parquet
primary_certificate_edges.parquet
abstention_cells.parquet
primary_canonical_labels.parquet
alternative_chart_labels.parquet
cell_labelable_fraction.parquet
```

### 探索性 Gate

沿用原计划：

| 指标                        |                   阈值 |
| ------------------------- | -------------------: |
| labelable measure         |             (\ge30%) |
| largest coherent region   |             (\ge20%) |
| unresolved + abstention   |             (\le70%) |
| x tertiles                | 三段均有 labelable cells |
| retained section geometry |                 全部通过 |
| root/search stability     |                   通过 |

这些阈值达到后，**立即进入 Student**，不等待 Formal Reach 或 (60%\sim80%) 覆盖。原交接也明确要求避免再次因为 Formal Gate 而完全跳过 Student。

# 八、20k–50k Exploratory Student 实验

## 实验目的

验证 section-first atlas 是否真正产生了“可学习的数据”，而不只是 Teacher 指标好看。

## 实验原理

Student 只学习最终 primary policy。alternative candidates、unused charts 和 abstention nodes 不得混入普通监督表。

## 数据划分

采用 task-space macro-block split，避免相邻点跨 train/test：

- train：(70%) spatial blocks；
- validation：(15%)；
- test：(15%)；
- 另外设置 chart-boundary test、long-loop test 和 historical paths。

## 模型对照

### S0：Global MLP

$$
xyz\rightarrow\beta_6
$$

这是论文优先保留的最简单表示。

### S1：Router + local experts

$$
xyz\rightarrow z
\rightarrow c_z(x)
$$

router 只能使用 xyz 可观测特征，不能输入 Teacher oracle chart ID。

### S2：MLP + one-step DLS

$$
\hat\beta_0=f_\theta(x),\qquad
\hat\beta_1=\operatorname{DLS}(x,\hat\beta_0)
$$

用于验证网络是否已经进入正确 basin。

### S3：MLP + two-step DLS

检验增加极少在线计算是否能显著降低 FK error。

### S4：Stateful diagnostic

$$
(x_t,\beta_{t-1})\rightarrow\Delta\beta_t
$$

只在怀疑存在历史依赖的 boundary/path 数据上训练，不替换主线。

### 论文中的基线

在同一 canonical dataset 上补充：

- MLP；
- LGBM；
- KNN。

这样模型对比才真正反映模型能力，而不是对多值标签的不同平均方式。

## Student 指标

主要指标不应只看 beta MSE，应包括：

| 指标 | 探索性要求 |
| ---------------------------------- | -----------: |
| FK position P95 | (\le5) mm |
| FK position max | (\le10) mm |
| closed-loop beta return max | (\le1^\circ) |
| chart-boundary beta jump | (\le2^\circ) |
| unreachable/abstention calibration | 单独报告 |
| inference time | 毫秒级 |
| DLS correction success | 单独报告 |

论文当前报告的路径最大误差是 (9.37) mm，因此 (5/10) mm 是与当前论文目标相容的探索性阈值。

# 九、何时选择不同的表示形式

## 9.1 保留 global xyz-only MLP

满足：

- stitched primary labels 在空间上单值；
- global MLP 达到 FK (5/10) mm Gate；
- chart-boundary 不发生明显 beta jump；
- closed-loop test 通过。

这是最优先结果，因为论文叙事最简单。

## 9.2 转 Router + experts

满足：

- 各 local expert 单独表现好；
- global MLP 的错误集中在 chart boundaries；
- chart domains 可以由 xyz 稳定分类；
- router 误分类主要发生在 stitchable overlap。

## 9.3 使用 abstention

当 nonstitchable region：

- 空间范围很小；
- 可以在 xyz 中明确定位；
- 删除后仍保留足够 coherent measure。

这比把整个模型改为 stateful 更合理。

## 9.4 转 stateful 的严格证据

应设计 paired same-xyz experiment：

1. 在疑似 boundary 选择 (50) 个 target xyz；
2. 每个 target 设计至少 (4) 条不同到达路径；
3. 每条路径重复 (5) 次；
4. 计算历史内和历史间 beta gap。

只有当：

$$
d_{\mathrm{within-history}}\le0.2^\circ
$$

但：

$$
d_{\mathrm{between-history}}>1^\circ
$$

并且这种差异：

- 在不同 solver/budget 下持续；
- 无法由 xyz 分区；
- 无法用小规模 abstention 隔离；
- static/router Student 发生可重复 jump；
- stateful Student 显著修复；

才宣布 beta inverse 需要历史状态。

当前没有这些证据，因此不能因为 raw candidate 多或者旧 B4–B32 漂移就转 stateful。

# 十、Gate 应如何重构

| 性质 | 当前 Gate | 新 Gate |
| ------------------ | ---------------------------- | ------------------------------------------------------------- |
| 几何一致性 | 与 numerical missing 混合 | 单独保留 P95/max、cycle、multipath |
| solver 鲁棒性 | 任意一次失败即整 patch fail | first-pass diagnostic + registered retry + persistent failure |
| chart 有效性 | 所有 root charts 必须通过 | 逐 chart qualification，可删除坏 chart |
| coherent region | 同 chart primary growth edges | stitched primary verified task graph |
| budget stability | S4 与 S8 | root/K/assignment 的最终 primary stability |
| boundary defect | 整 patch fail | split 或 abstain，重新计算 coherent measure |
| Formal certificate | 与探索阶段混在一起 | 探索、Student、Formal 分层 |

必须继续保留的硬条件：

- actual bounds；
- FK residual (\le3) mm；
- geometry P95 (\le0.5^\circ)；
- geometry max (\le1^\circ)；
- repeat P95 (\le0.2^\circ)；
- retained primary certificate 中没有 unresolved critical edge；
- 监督数据一物理点一个 primary label；
- 不使用 row padding；
- 所有监督 rows 都计入 (200{,}000) 总预算。

# 最终实验决策

当前可以立即做出的决策是：

- **停止继续扩大 F1 candidate flood。**
- **保留 section-first 作为唯一主线。**
- **暂不把当前 exact S4 宣布为最终方法。**
- **退役 `missing_count==0` 作为几何 mechanism Gate。**
- **退役当前 `_component_ratio()` 作为 coherent region Gate。**
- **将 chart-transition audit 前移到 patch 阶段。**
- **先把当前方法准确称为 rooted greedy section，而非已验证的 beam search。**
- **完成 V14.2R 后直接做 12-patch，不再增加新的四 patch 方法消融。**
- **12-patch 通过后立即做 5k 和 Student，不等待 Formal Reach。**

从整体实验目的看，下一轮最重要的结果不是再证明“能找到更多 IK”，而是回答：

$$
\boxed{
\text{经过 chart qualification、stitching 和全局路由后，是否能得到一张足够大的、可验证且可学习的静态 canonical inverse atlas？}
}
$$

这个问题一旦由 repaired 5k 和 Student 回答，论文第 4 节的核心实验链条就真正建立起来了。

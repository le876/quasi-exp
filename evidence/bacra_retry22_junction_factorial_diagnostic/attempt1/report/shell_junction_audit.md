## 问题记录：Student 为什么会整体学歪

状态：**机制已部分验证；指定近轴路径已修复；全域尾部原因尚未唯一确定。** 此问题已有[Q33 结果记录](../2026-09-12-retry21-q33-results.md)的“合法标签平均机制”和“全域与 outer 尾部”作为证据，本节把问题及剩余疑点明确登记。

“整体学歪”指目标路径在网络输出后出现显著位置、尺度或构形偏离，不能泛化为所有点都失败。其已验证机制是：IK 可以多解，β 空间的平方误差折中不保证末端位置正确。镜像合法解的平均 β=0 会产生 130 mm 误差。近轴样本稀少使普通全域抽样难以充分约束这一问题；本轮 FK 任务损失与加采样的组合明显有效，但不能把每个单独因素都说成已证实的充分原因。

第二轮没有改训练数据，两种子已使指定八条近轴路径各 960 点全部≤3 mm。因此旧近轴问题不能解释成“只有扩数据才能修好”。仍待解释的尾部包括：训练点本身被严重拟合错、同一点在不同种子下差异巨大、失败在两域交界邻域聚集。

后续必须区分三个因素：目标空间的缺点/稀疏、监督 β 分支的不相容、训练采样与非凸优化。不能由点云外观直接断言最后两者，也不能由 Teacher 逐点合法断言连续可学。

这一机制与 Bishop 的原始研究一致：平方误差估计条件均值，而多值逆问题中的有效解均值可能无效；论文包括机器人 IK 例子。[Mixture Density Networks，1994](https://www.microsoft.com/en-us/research/publication/mixture-density-networks/)。这只支持机制，不证明本项目需要更换为该论文的模型。

## 严重失败与衔接邻域有明显关联

对每个完整 on-grid test 点，从原 train 中寻找欧氏距离最近的 32 个点。邻居同时含 primary 和 outer 时记为“两域混合邻域”；不使用 test 标签构建邻域。

| 统计 | seed20260925 | seed20260926 |
| --- | ---: | ---: |
| 全部 test 点 | 8,272 | 8,272 |
| 误差>50 mm 的 test 点 | 27 | 33 |
| 其中位于两域混合邻域 | 22/27（81.5%） | 30/33（90.9%） |
| 混合邻域失败率，分母 1,111 | 1.980% | 2.700% |
| 非混合邻域失败率，分母 7,161 | 0.0698% | 0.0419% |

混合邻域只占 test 的 13.43%，却包含大多数严重坏点。以真实分界前后各 5 mm 的带状区域复核：99 点中两种子各 5 点>50 mm（5.05%）；其余 8,173 点为 22/28 点（0.269%/0.343%）。用户指定 X=1,028.59±10 mm 区域共有 587 个 test 点，两种子各 5/12 点>50 mm；真实分界附近的风险更集中。

结果见 [boundary_bands.csv](../../runs/diagnostics/retry21_shell_junction_20260913/boundary_bands.csv) 与 [failure_neighborhoods.csv](../../runs/diagnostics/retry21_shell_junction_20260913/failure_neighborhoods.csv)。带宽、k=32 和 50 mm 是这次事后诊断的观察尺度，不是新的通过门槛；点之间有空间相关性，不把上述比例当独立样本因果检验。

然而“交界相关”仍不等于“只因缺少数据”：

1. 全体 test 到最近 train 的距离中位数为 17.016 mm；两种子的严重坏点分别为 17.250/18.057 mm，未普遍表现为更大的近邻空洞。
2. seed1 坏点的 k32 标签均值 FK 误差中位数 12.405 mm，局部 β 最大跨度中位数 4.097°；相比全体 test 的跨度中位数 5.578°并不更大。局部原标签冲突不能直接解释全部大误差。
3. 相同数据下，`fk_balanced` 在真实分界±5 mm 的 99 点中没有>50 mm 的失败，第二轮两种子却各有 5 个。模型结构、预算和采样都变了，不能把差异唯一归给其中一项，但足以说明数据位置并非唯一决定因素。
4. 两种子 train 中仍有 71/72 个点>50 mm，最大 141.102/118.606 mm；训练点已有明确监督也可能失败。

已有 10,864 条跨域 train k16 边中，合法端点的 β 中点产生的 FK 弦中点失真 P95=4.635 mm、max=69.418 mm，237 条>10 mm。说明某些衔接确实存在标签插值风险；边长中位数 26.579 mm，尚未进行同距离、同半径、同方位的域内配对对照，不能把全部差异归为生成来源。

另一个可检验因素是训练覆盖权重：outer 占 train 的 61.38%，但第二轮只有全域均匀部分能抽到 outer，期望 batch 占比降到 **24.52%**。分区 core/transition/tip 的边界是硬的。此事实支持做采样对照，不证明 outer 退化一定由减采样造成。

## 保持 X 范围的增厚是否有依据

有依据，尤其是 outer 壳内侧及其与 primary 的过渡区域。当前 primary 已经有一定体积内填，不能把整个数据集称为一张薄表面；outer 仍主要继承 annular 分布。其全部 44,726 行的最小径向距离为 214.960 mm；在 X=980–1000 mm 切片中，2,112 行的最小径向距离为 290.035 mm。分布图显示两侧内边界和径向占据差异明显。

为了区分“没有采到”和“根本不可达”，本次只读使用旧的 32,768 行 full FK seed bank，SHA-256 `db41666d24a27b3799b223e9122b6375b8fdff533f9ed89e3cc7f1626ac79d42`。在 `900≤X<1015.498 mm, rho<200 mm` 条件下找到 **55 个现有 FK 构形位置**：

- 实际 X 范围 931.509–1,015.347 mm，rho 范围 60.528–198.950 mm。
- β 全部满足当前 bounds；用当前环境 reference scalar FK 复核，和记录坐标最大差 2.46e-13 mm。
- 到当前完整 L1 数据集的最近距离为 12.040–93.819 mm，中位数 33.636 mm。

证据见 [existing_interior_witnesses.json](../../runs/diagnostics/retry21_shell_junction_20260913/existing_interior_witnesses.json)。这证明在当前 X 范围内，至少部分壳内侧空间确实有合法构形而缺少监督支持。旧 seed bank 是非均匀经验见证，不是完整可达体积或全方位覆盖的分母；其 β 也不自动成为新的统一 Teacher 标签。

当前几何缺口不限于 outer：retry20 实际 L1 在原冻结 primary required cells 上的几何体积服务率为 **82.081%**，最低轴向切片为 **79.588%**，均来自 `02_dataset/coverage_audit.json`。这些值只适用于原 88,168 cells、10 mm 服务语义，不能外推为全部当前 X 范围覆盖率，也不能说补足 cell 中心就能保证轨迹成功。

## 当前方法能支持什么，下一步怎么验证

当前 XYZ→β 网络、可微 FK 损失、训练/验证划分和直接 raw 推理都不要求目标只落在壳面上，从实现上可以处理更厚的三维目标区域。零位约束也不限制这些位置。需要扩充的是目标注册、标签生成与局部衔接检查、分区采样和覆盖验收；现有 retry21 runner 冻结旧输入哈希及配额，不能直接往原 Parquet 塞新点再当同一实验续跑。

建议顺序是 **先在交界附近做有控制的增厚试验，再扩大到整个已有 X 范围**：

1. 先固定当前数据、相同网络/预算/种子，对照当前采样与增加交界/outer 曝光的采样。保持 FK 损失和零位结构一致，检查尾部能否在不增数据时缓解。
2. 固定一段跨越真实分界的三维过渡带；按 X、rho、方位角注册目标 cell 和内部探针，覆盖当前壳内边界及两侧重叠区域。只对确有支持的内侧逐层推进，保留 solver unresolved，不能假定所有截面都能填到轴线。带宽和层厚须在下一轮协议中结合最近邻尺度、试求解率、预算冻结，本审计不替代该决策。
3. 用相同新增点数与训练更新预算，比较“原覆盖域加密”和“交界/内侧定向增厚”，让实验能够区分单纯增加样本量与增加厚度。训练、validation、test 按既有空间规则划分，新数据不能进入原 held-out blocks 造成泄漏。
4. 新旧标签在重叠邻域共同做合法性与分支检查。单独保存 XYZ 几何间隙、β 邻接差异、β 中点 FK 失真和模型误差；不要对不同合法分支直接平均 β 来制造平滑。必要时比较同坐标下的局部分支重选；只有一致分支方案仍失败，再判断是否需要条件分支或专家模型。
5. 固定旧 35 条路径与完整 on-grid/off-grid 分母，同时添加穿越接缝、沿新增径向厚度走的独立轨迹/切片。除全域 P95，还看>50 mm 坏点数量、max、跨种子失败、原近轴≤3 mm 保留率、旧 outer 退化数，以及新增可达 cell 服务增益。

每个 cell 的填充和成功轨迹都按新增目标分母核算；只有点数增加、点云视觉更厚或局部 IK 成功，不算完成扩充目标。新执行实验需要新 protocol/source/binding、冻结分母及资源预检。本次没有启动扩充或训练，也没有得到“补厚已经解决尾部”的结果。

## 本次结论

用户关于两部分衔接的观察得到了定量支持，应列为下一轮优先排查区域。保持 X 范围、向壳内侧增加厚度有明确的现有 FK 见证，当前学习方法在结构上支持这种扩充。最有根据的工作假说是“几何分布、标签分支和训练权重在交界附近相互作用”，尚不能收敛为“单纯数据少”或“全部由接缝造成”。
